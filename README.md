# 市场状态识别 · Market Regime Recognition

国内商品期货市场状态识别系统。核心定位是 **nowcast（当前状态识别）而非 forecast（涨跌预测）**：方向基本不可预测（信号半衰期约 12h），但波动率与状态可识别。用途偏**风控 / 纪律（防守型）**，而非择时 alpha。

---

## 核心结论

| 问题 | 结论 |
|---|---|
| 用哪个周期？ | **60min 单一主信号**（五周期收敛：响应拐点 + 降噪 + 94% 共同因子） |
| 识别还是预测？ | **识别（nowcast）**，不是预测涨跌 |
| signal 怎么算？ | `signal = sign(R) × min(E/eff, 1)` |
| 项目定位 | 风控 / 纪律（防守型），非择时 alpha |

---

## 算法伪代码

```
输入：品种 p 的 1 分钟行情（open/high/low/close/volume）
     重采样为 60min K 线
参数：win = 27（回看根数，≈3 交易日），eff = 0.44（趋势效率阈值）

# 1. 平滑价格（Hull Moving Average）
HMA(n) = WMA( 2 * WMA(close, n/2) - WMA(close, n), sqrt(n) )
c      = HMA(close, win)

# 2. 方向 R（平滑价过去 win 根涨跌幅）
R = c[t] / c[t-win] - 1

# 3. 路径能量（近 win 根单根涨跌累计）
U = Σ max(Δc, 0)          # 累计上行
D = Σ max(-Δc, 0)         # 累计下行
Δc = c[t]/c[t-1] - 1

# 4. 趋势效率 E（净位移 ÷ 总路径）
E = |R| / (U + D)

# 5. 连续强度 signal ∈ [-1, +1]
signal = sign(R) * min(E / eff, 1)

# 6. 六态分类 → 方向建议
if 异常(跳空/波动突增/涨跌停):
    state = 高波动异常,  建议 = 回避
elif |signal| <= 0.3:     state = 震荡,      建议 = 观望
elif 0.3 < signal <= 0.7: state = 偏多,      建议 = 看多(弱)
elif signal > 0.7:        state = 强多,      建议 = 看多(强)
elif -0.7 <= signal < -0.3: state = 偏空,    建议 = 看空(弱)
elif signal < -0.7:       state = 强空,      建议 = 看空(强)
```

**直觉**：$E$ 衡量趋势「直不直」——$E=1$ 是直线单边（无回撤），$E\to 0$ 是原地打转。$signal$ 把「方向 × 效率饱和度」压缩到 $[-1,+1]$：+1 强单边涨、-1 强单边跌、0 震荡。$eff$ 取历史趋势效率的 p88 分位。
